# 包装来稿与任务分流

适合收到了包装照片、产品图、源文件、实盒信息或文字需求，但需要先判断下一步的场景。输出缺项与可继续项，不自动生成设计、刀模或印刷文件。

将本文件夹作为技能包使用，入口为 `SKILL.md`。示例请求：“只有餐具照片，先帮我分清能做什么，还缺什么”；“已有定稿只需换Logo，别重做整套设计”。

与 packaging-design-workflow 的区别：总流程负责从设计到交付；本技能只负责入口诊断与续作分流。没有强制软件依赖，不捆绑脚本、模型或客户素材。
